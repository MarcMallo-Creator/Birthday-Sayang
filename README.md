# Birthday Website — For Sayang

A romantic, elegant and minimalist birthday website for 2 October 2026.

## Files
- `index.html` — main page
- `style.css` — design
- `script.js` — countdown + interactions
- `images/` — uploaded memories

## Deploy to Vercel
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. In Vercel, choose **Add New → Project** and import the GitHub repository.
4. Framework preset: **Other** (or leave auto-detected).
5. Deploy.
6. Vercel will give you a `.vercel.app` link.

No build command is required.

## Important
The birthday countdown uses Malaysia time (UTC+8) and targets 2 October 2026.
